# 政企园区与供应商端 · 资料索引

更新时间：2026-10-28。适用范围：供应商端与政企园区客户端的后续需求、设计、前端实现及验收。本目录根据当前仓库资料整理，作为工作索引；业务正式规则以经确认的 PRD、接口和最新用户决定为准。

## 如何使用

1. 开始任务先读本页与 [双端业务与项目把控](./双端业务与项目把控.md)。
2. 新增或修改页面，读 [设计与前端规范](./设计与前端规范.md)，再读对应端的现有页面、组件与样式。
3. 改动服务、订单、园区或主体等跨端对象时，核对两端数据与状态；接口未知的部分记录待确认，勿把演示数据当作真实联通。
4. 用户确认的新规则写入对应来源文档，并更新本目录索引和日期；冲突时记录新旧决定及原因，避免静默覆盖。
