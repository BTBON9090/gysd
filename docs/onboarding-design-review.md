# 服务商入驻 Demo：设计复盘与验收

依据：`万联易达ZQ供应商端-供应商入驻-PRD.md` §6.6；用户对 V2 视觉、首页、按钮与验收工具的反馈。范围仅为服务商入驻前端演示。

## 发现的问题与 V2 处理

| 发现 | 对用户的影响 | V2 处理 |
| --- | --- | --- |
| 灰底、灰字与多层边线叠加 | 表单信息层级弱，字段扫读费力 | 入驻页改为近白底、深色正文；输入边框保留用于识别，分组主要靠留白 |
| 表单组间间距接近字段间距 | 长表单缺少节奏 | 组间留白增大，分组标题使用少量青绿色标识；证照、协议块分段展示 |
| 辅助色分散且重点不清 | 已核验、当前步骤、说明难以快速定位 | 蓝色用于主要操作与当前步骤，青绿用于已核验/帮助，暖色用于待审核与错误状态 |
| 过宽的“上一步/下一步”及混杂的底栏导航 | 当前操作与跨页面导航难区分 | 底栏仅保留步骤动作、暂存和删除草稿；“入驻首页”“返回工作台”移入顶栏 |
| 首页只呈现单张服务商卡片 | 缺乏将来扩展供应商类型的结构 | 类型选择区展示本期服务商入口和“更多类型”占位；未定义类型禁用，不补造业务规则 |
| 首页放置完整申请列表 | 首页职责与 PRD §6.6.1 不一致 | V2 首页只发起申请；已有主体通过顶栏切换并按状态跳转 |
| 验收工具拖动后归位、需手动收起 | 对比版本时反复遮挡页面 | 坐标本地持久化；打开/关闭共用坐标；点击面板外自动收起；面板在视口内定位 |

## 设计约定

- 目标：让申请人在五步表单中快速看清字段、确认当前状态、完成提交。
- 主体：白色页面、深海军蓝文字、蓝紫色主操作；青绿仅作状态与小面积提示，错误用红色。参考 Linear 浅色界面对内容优先级与对比度的处理，不复制其品牌视觉。
- 密度：字段内紧凑，字段组间明显放宽；输入控件仍保持可识别边界。边框用于输入和交互控制，静态内容靠底色与留白组织。
- 反馈：选择、悬停、聚焦、上传、校验、暂存、提交与审核状态都在当前页给出可见响应；演示动作标明“演示”。
- 版本：验收工具可切换 V2 清亮版、V1 上一版与 V0.9 原型参考；V2 为默认预览，V1 保留供比较。版本切换不改变业务数据。

## PRD 与 Demo 边界

- 已接入演示闭环：申请入驻 → 主体闸口 → 五步向导 → 提交审核 → 审核中/驳回/通过进度；可暂存、恢复、删草稿、驳回后修改再提交或取消；审核中只读。
- 真实服务端主体查询、二要素、工商详情、OCR、附件持久化、审核操作与协议正文均未接入。当前交互为前端模拟，不能作为接口验收结论。
- PRD 中若干字段表和异常文案为嵌入 `<sheet>`，本地 Markdown 无法读取其内容。字段、枚举、默认值和错误文案需拿到表格原文后逐项复核；当前 Demo 不应作为这些隐含细则的唯一依据。
- 首页其他类型仅为信息架构扩展位。其正式名称、条件、字段与开放时间均待业务定义。
- 第二轮验收为检视多类型布局，首页加入“制造类 / 贸易类 / 物流类”三个**设计示例**；全部标记“示例”，不可申请，不进入业务模型。
- PRD 附录 A 指定服务范围来自中台通用省市接口，擅长业务领域来自嵌入字典表。Demo 现使用可搜索的级联多选与多选下拉，静态选项仅为交互样例，不能视为完整字典。
- 本次用户明确选择不做无障碍专项设计与验收；保留组件现有基础能力。

## 验收入口与检查结果

- 本地预览：`npm run dev -- --host 127.0.0.1 --port 5176`，打开 `http://127.0.0.1:5176/#/onboarding`。
- 页面右侧“验收”按钮：拖动、打开、切换 V1/V2、点击空白处收起、刷新后保持位置。
- 可从“申请入驻”走全流程；验收工具与步骤卡片提供演示填入，以便审阅五步与审核状态。
- 2026-09-23：`npm run typecheck` 与 `npm run build` 通过；浏览器检查 V2 首页、五步表单的首步、版本双向切换、拖动/收起/刷新位置持久化。视觉由设计/业务负责人最终验收。

## 第二轮批注处理

- 主体已入驻与模拟二要素改为一致的专用状态弹窗；草稿/驳回取消的确认弹窗采用统一样式。
- 真实图片点击文件后直接进入蒙层查看；PDF 直接进入内嵌预览。演示填入无真实文件时明确展示占位说明。
- 资质分组增加序号、标题字重、状态标签和组间分割线；协议模板动作跟随各协议标题。
- 确认页将字段名和值组成独立信息单元；第五步提示统一为“本步说明 / 提交前检查”。
