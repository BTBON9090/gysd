# 供应商端业务页面工程工作单

## 来源与边界

- 依据：供应商入驻 PRD、服务上下架 PRD、完整交易流程 PRD。
- 对象：已入驻服务商管理员；另一角色的园区审核、客户确认、支付与财务动作由验收工具驱动。
- 数据：当前主体独立的浏览器本地演示数据；正式开户、SSO、上传、订单、分账、发票均待后端接口接入。
- 视觉基线：用户认可的入驻首页和五步入驻流程。浅色、白底、内容分组、清晰标题、圆角矩形按钮和标签、轻量反馈。桌面优先。

## 验收路径

1. 验收工具切已入驻，填入交易场景。
2. 我的园区统计跳至服务、订单、评价；申请加入园区。
3. 店铺资料保存、案例创建与服务关联。
4. 服务发布四步、暂存、提交；验收工具模拟园区审核；上下架与删除限制。
5. 钱包未开户阻断发布；开户后订单合同和交付经外部回调推进。
6. 售后退款阻断订单操作；对客退票后才退款。
7. 发票合并规则、平台财务回调和评价一次初评一次追评。
8. 空态、错误反馈、窄视口、构建与浏览器运行。

### 复杂样例

入口：`/#/order/DEMO-ORDER-MULTI-001`，或验收工具“打开三期付款与退款订单”。首次自动补入当前主体，不覆盖现有业务数据。补入标记避免清空后重复自动生成；验收按钮可以主动补回。

| 阶段 | 应付 | 累计支付 | 已退款 | 初始履约状态 |
| --- | ---: | ---: | ---: | --- |
| 需求诊断与方案 | 38,400 | 38,400 | 2,400 | 验收通过 |
| 系统配置与联调 | 51,200 | 51,200 | 0 | 验收驳回；8,500 元退款待处理 |
| 上线培训与移交 | 38,400 | 0 | 0 | 未开始，待付款 |
| 总计 | 128,000 | 89,600 | 2,400 | 剩余实付 87,200，待付 38,400 |

另有第二阶段已取消退款（1,000 元）和第一阶段已退票（38,400 元），取消申请不产生资金支出。订单包含客户需求、需求附件、合同、阶段交付文件及驳回意见。

资金口径：`paid` 是累计入账，`refunded` 是实际退回；剩余实付 = paid − refunded；未付款 = amount − paid。退款不会重新制造待付款。单阶段退款记录关联 stageId；整单退款在演示中从最近已支付阶段依次分摊，以保持阶段账与总账相符。正式分摊以服务端结果为准。

合同与交付的新上传文件存入本地 IndexedDB，支持 PDF/图片预览与原文件下载。历史样例文件展示明确标识的示例内容，不冒充正式合同/附件。发票保留前端演示记录，通过订单筛选深链进入发票模块。
