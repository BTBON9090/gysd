# UI 项目偏好卡

适用范围：本仓库服务商入驻前端演示。需求以仓库根目录 `万联易达ZQ供应商端-供应商入驻-PRD.md` 为准，用户补充的视觉和导航要求适用于 V2。

| 项目 | 当前约定 | 依据 |
| --- | --- | --- |
| 交付深度 | 可运行前端 Demo，模拟接口与数据明确标注 | 用户说明只做前端演示 |
| 业务范围 | 只完善服务商入驻闭环；未定义的其他类型不填业务字段 | 用户指示与 PRD §6.6 |
| 主题 | 浅色、干净、清晰，参考 Linear 的视觉秩序 | 用户反馈 |
| 设备范围 | 保留桌面工作台；入驻独立页在窄窗口可用 | 当前项目结构与本次入驻需求 |
| 语言 | 简体中文 | 项目现有界面与 PRD；其他语言待业务决定 |
| 动效 | 仅快速的悬停、聚焦与状态反馈 | 用户要求填表干脆利索、做好交互反馈 |
| 无障碍专项 | 不启用 | 用户明确答复“默认不启用” |
| 设计版本 | V2 清亮版默认，V1 保留对比 | 用户要求作为验收工具中的新版本 |
| 数据与接口 | 本地模拟，不上传真实主体资料 | 前端 Demo 范围 |

2026-09-23：新增 V2 与本卡。后续业务字段、枚举和异常文案以 PRD 嵌入表格原文复核，不根据设计猜测。
