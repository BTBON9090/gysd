# 万联易达 · 供应商端演示

Vue 3 + TypeScript + Vite 的纯前端 Demo。包含服务商入驻、个人信息、成员管理、切换供应商和切换园区客户演示。业务字段与规则以本地入驻 PRD 为准；页面中的演示数据和未开放供应商类型都标有说明。

服务管理当前仅展示 PRD 已定义的入驻「产品服务」资料。该 PRD 尚未定义服务商品发布、上下架、订单等字段与规则，因此页面没有虚构这些操作。切换园区客户会进入本仓库内的目的地演示页；正式环境需配置园区客户端地址和 SSO 接口。

## 本地运行

```bash
npm ci
npm run dev
npm run typecheck
npm run build
```

默认地址为 `http://127.0.0.1:5175/#/workspace`。未入驻时，工作台内容区即为入驻首页，左侧保留工作台和基础设置；入驻全流程在同一工作台框架内完成。页面右侧有「验收」工具，可切换设计版本、快速填表、查看审核状态和记录问题。此工具也包含在生产构建中。

## Netlify 部署

仓库根目录的 `netlify.toml` 已设置构建命令 `npm run build`、发布目录 `dist`。在 Netlify 连接此 GitHub 仓库后，使用默认配置即可构建。入口是站点域名后的 `/#/workspace`；项目使用 Hash 路由，不需要服务器端的 SPA 重写规则。

此 Demo 不接后端。入驻申请、个人资料、成员、验收版本和工具位置存于访问者自己的浏览器，浏览器之间不会共享数据；主体查询、二要素、OCR、审核结果和成员开户均为前端模拟。登录与退出仅控制演示会话，不提供真实身份认证。协议模板为占位文件。未开放的供应商类型仅用于展示首页扩展布局，不会创建申请。

设计调整与 PRD 对照见 `docs/onboarding-design-review.md`。
